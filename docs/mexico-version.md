- **Cities:** 5 cities × 5 places = 25 places and 25 characters, generated by the adapted script. Costs cents.
- **Images:** about 55 (5 cities, 25 places, 25 portraits). Use the 2026-10-11 lessons: put the location in every place prompt and set the image size in the request (see [Roadmap → Now](06-roadmap.md#now-ranked), image sizes).

- **Character prompt:** copy and adjust a few lines (formality words, reply key).
- **Voices:** the real effort. ElevenLabs Flash v2.5 speaks Spanish, but Mexican accents need vetting by ear (an hour or two of listening). iPhone fallback voices exist for es-MX (Paulina, Juan).

## Clone or generalize?

**Decided (Josh, 2026-10-11): one codebase.** Some things have to be country-specific, but improving the app should improve every country wherever possible. Corollary: when something is shared in spirit but written per language (like the character prompt), prefer a shared template with only the language-specific words filled in, so an idea like "characters can't hear your pronunciation" is added once.


- **Clone** (copy the repo, find-and-replace): fastest on day one, about a day. But every fix lands twice (voice fallback, error handling, memory, the database), and the apps drift apart within weeks.
- **Generalize** (language packs, one codebase): about half a day more up front, then every improvement benefits both.
- **Chosen:** one codebase, two Railway services, each with a `LANGUAGE` setting (`it`, `es-mx`). Separate URLs and apps to the user, shared code underneath. This is what [Architecture → Keeping other languages possible](05-architecture.md) already intends.

## Risks beyond the code

- **Language quality:** Mexican usage differs from Claude's default Spanish (when to use *usted* vs *tú*, *¿mande?*, *ahorita*). Someone who knows Mexico should play it before trusting it.
- **Persona and name:** the vision's *amante dell'Italia* needs a Mexican counterpart, and "Fuori" is Italian; the Mexico app wants its own name.

About 1 day of code generalization (mostly Claude Code work) plus about a day of content, images and voice vetting.
